InvalidReject an unverifiable token and never display a false received status.
UnavailableFail closed when the signing secret or service dependency is missing.

Usage rules

  1. Legal meaning is owner-controlled. Design changes may alter structure and typography, never obligations.
  2. Every repeated state has a text label, keyboard focus and a mobile layout.
  3. Tables scroll inside their own boundary. The document viewport never overflows.
  4. Print removes navigation, preserves provenance and avoids orphaned headings.
  5. Production callbacks reject unverified signatures and missing secrets.
